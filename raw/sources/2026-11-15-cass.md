### cass

| Aspect | What the README says |
| --- | --- |
| Sources | 34 connectors. Each turns one tool's session format into a common form: tool, project folder, messages, time. |
| Storage | SQLite is the source of truth for indexed conversations. Search indexes are derived and can be rebuilt. |
| Search | Word search always; search by meaning with an optional local model |
| Other machines | Pulls sessions from other machines over SSH and rsync into one index |
| Kept copies | Keeps its own raw copy of session files, because tools delete their own logs |
| For agents | A JSON mode on the command line |

### cass-memory

| Layer | What it holds |
| --- | --- |
| Episodic | The raw sessions, through cass |
| Working | A "diary" entry per session: accomplishments, decisions, challenges, learnings, preferences |
| Procedural | A "playbook" of rules for agents, each with a score |

| Mechanism | What the README says |
| --- | --- |
| Feedback | Each "helpful" or "harmful" mark is a stored event with a time. The score is worked out from the events. |
| Decay | A rule's confidence halves every 90 days without new support |
| Harm weighs more | One harmful mark counts four times one helpful mark |
| Evidence gate | A proposed rule is checked against past sessions before it is accepted |
| Who decides | A model proposes rules. Fixed code, with no model, accepts, merges and retires them. |
| Secrets | Patterns for keys, tokens and passwords are removed before text is processed |

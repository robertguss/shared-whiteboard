## Summary

A visual knowledge tool, 28 years old by its own count. Version 15 is free on the desktop and adds an AI assistant called Cerebro.

| Aspect | What the sources say |
| --- | --- |
| Unit | A "thought" |
| Links | Three kinds: parent, child and jump. A jump is a lateral link with no hierarchy. A thought can have several parents. |
| Main view | The "Plex": one active thought in the centre, parents above, children below, jumps to the side |
| Other views in version 15 | Card View, Mind Map, Tree View |
| AI | Cerebro: summarise, create thoughts, search, suggest links, run "agentic scripts" |
| Data outside the app | A forum thread discusses a `links.json` file, so some JSON form exists. Unverified what an outside program can read or write. |

# Scan of existing tools, 15 November 2026

One web search and a reading of each project's README or homepage. No tool was installed or run. Repository numbers come from the GitHub API on the retrieval date.

## canvai

- URL: https://github.com/chuck00lin/canvai
- Stars 3. Created 2026-07-03. Last push 2026-07-22. MIT.
- A browser whiteboard where a coding agent and a person edit the same board. Boards are JSON Canvas files in the repo under `discuss/`. The agent edits over MCP with semantic operations and never sends coordinates; an ELK layout engine places nodes. A card the person drags is pinned and auto-layout flows around it. "Rails" give ordered lists such as timelines.
- Runs with `npx @chuck00lin/canvai serve` on `127.0.0.1:5199`; remote access by `--host 0.0.0.0 --token` or a tunnel.

> Boards are plain JSON Canvas files in your repo, versioned by git.

> Any card you drag is **pinned**: `auto_layout` flows around it, and the agent picks up your arrangement on its next read.

> The board *protocol* is still soft

## Maproom

- URL: https://github.com/Raggertooth/maproom
- Stars 1. Created and last pushed 2026-10-11. MIT.
- Mind maps for AI-assisted development. A browser editor and an MCP server share one local JSON file. Topics carry text, notes, status, colour and parent. Cross-links are supported. Exports OPML and SVG.
- Stated limits: layout is automatic with no free drag-and-drop canvas; one local JSON file; stdio MCP only.

## Vync

- URL: https://github.com/PresenceWith/Vync
- Stars 1. Created 2026-03-08. Last push 2026-04-04. MIT.
- A local-first visual planning tool. A `.vync` JSON file is the source of truth and syncs both ways between a web UI, a desktop app, Claude Code and any text editor.

## Nimbalyst

- URL: https://nimbalyst.com/
- A desktop and iOS workspace for running Claude Code and Codex sessions with visual editors for tasks, markdown, diagrams, mockups and mind maps. Mind maps are stored as plain-text `.mindmap` files. Described as MIT licensed and free for individuals.

## Arango

- URL: https://arango.ai
- An enterprise "contextual data platform" built on a graph database. It ingests company data, builds a knowledge graph automatically, and serves it to AI agents through graph and vector retrieval. Sold on scale, governance and high availability.
- It has no visual work surface for a person.

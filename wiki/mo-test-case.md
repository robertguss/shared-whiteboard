# Mo as the test case

Mo is Robert's programming language project (`robertguss/mo`, public). They named it as the example this tool should handle: large, fast-moving, and already pivoted and restarted.

## Why it is a good test

| Fact | Value |
| --- | --- |
| Age on 15 November 2026 | 5 weeks, first commit 11 October |
| Commits | 826 |
| Markdown documents, excluding vendored code, benchmarks and agent worktrees | 181 |
| Phases on the roadmap | 9, numbered 0 to 8 |
| Finished | Phases 0 to 5 |
| Releases | v0.1.0 approved 7 November, v0.2.0 approved 11 November |
| Now | Phase 6, intent and autonomy: design approved, nothing implemented |

## What a board of Mo must show

- All phases and the features in each, in order.
- For each item: built, in progress, next, needs research, or dropped.
- The pivots and restarts, as part of the history.
- What is coming up.

## Current record in Mo

Progress lives in `docs/ROADMAP.md` as a phase table and checklists. Any board has to coexist with that file or replace it. Which one is an [open question](open-questions.md).

# Requirements so far

What Robert has asked for. Each line traces to his words in the first session record. Nothing here is a design.

## Wanted

| # | Requirement | His words |
| --- | --- | --- |
| 1 | See ideas visually, not as files of text | "too many files and too much text and its hard for me to see the connections" |
| 2 | A free, infinite board where notes move anywhere | "an infinite whiteboard where notes and things can be moved around freely" |
| 3 | See a project's history, including pivots and restarts | "a timeline so I can see the history of a project" |
| 4 | See what is built, what remains, what needs research | "which have been built and which remain and which still need research" |
| 5 | See what is coming up | "what is coming up what has been done" |
| 6 | The person and the agent both use, edit and modify it | "both AI agents like claude code and myself can use, edit and modify" |
| 7 | The agent understands hierarchy and relationships as the person does | "read it and undersfand the hierarchy and relationships just like I do" |
| 8 | The agent keeps it current | "Maintenance and upkeep is not that difficult because the agent does that" |
| 9 | Simple, with AI built in from the start | Tinderbox "has way too many features and is overly complicated and AI has just been bolted on" |

## Not wanted

| What | Why |
| --- | --- |
| Pages and databases | Notion "wasnt visual enough"; the overall picture and progress over time were hard to see |
| A large feature set | See requirement 9 |

## Not yet known

Whether it is one HTML file or an app. Robert raised this in his opening request and it is still open. See [open questions](open-questions.md).
